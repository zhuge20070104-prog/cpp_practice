# 编译器自动向量化详解

## 概述

**自动向量化（Auto-vectorization）**：编译器自动将普通的串行代码转换为SIMD并行代码，无需程序员手动编写。

## 关键问题

### ❓ 是只有Intel编译器才会自动向量化吗？

**❌ 不是！现代主流编译器都支持强大的自动向量化。**

| 编译器 | 自动向量化 | 向量化报告 | 跨平台 |
|--------|-----------|------------|--------|
| **GCC** | ✅ 非常强大 | `-fopt-info-vec` | ✅ |
| **Clang/LLVM** | ✅ 非常强大 | `-Rpass=loop-vectorize` | ✅ |
| **Intel ICC/ICX** | ✅✅ 最强（毕竟是Intel的） | `-qopt-report` | ❌ 仅x86 |
| **MSVC** | ✅ 支持 | `/Qvec-report:2` | ❌ 仅Windows |

### 结论

✅ **GCC和Clang的自动向量化非常强大，不输Intel编译器！**  
✅ **简单的循环，现代编译器都能自动向量化**  
✅ **性能通常和手写SIMD相当**  

## 什么是 "packaged single float data"？

**Packaged Single Float Data** = 打包的单精度浮点数据

- **Packaged（打包）**：把多个数据组合在一起
- **Single（单精度）**：32位float
- **Float Data（浮点数据）**：浮点数

### 示例对比

```cpp
// 普通处理：一次处理1个float
float a, b, c;
c = a * b;  // 1个乘法

// 打包处理（SSE）：一次处理4个float
__m128 [a0, a1, a2, a3]  // 4个float打包在128位寄存器中
__m128 [b0, b1, b2, b3]
mulps  [c0, c1, c2, c3]  // 4个乘法同时完成！
```

## GCC自动向量化测试

### 测试代码

```cpp
#include <iostream>
#include <chrono>

// 测试1：简单循环 - 容易被向量化
void simple_add(float* __restrict__ a, 
                float* __restrict__ b, 
                float* __restrict__ c, 
                int n) 
{
    for (int i = 0; i < n; i++) {
        c[i] = a[i] + b[i];  // 完美的向量化候选
    }
}

// 测试2：MAD（Multiply-Add） - 容易被向量化
void multiply_add(float* __restrict__ a, 
                  float* __restrict__ b, 
                  float* __restrict__ c, 
                  float* __restrict__ result, 
                  int n)
{
    for (int i = 0; i < n; i++) {
        result[i] = a[i] * b[i] + c[i];
    }
}

// 测试3：有依赖的循环 - 难以向量化
void dependent_loop(float* data, int n)
{
    for (int i = 1; i < n; i++) {
        data[i] = data[i-1] + data[i];  // 依赖前一个结果
    }
}

// 测试4：带if的循环 - 可能被向量化（但效率降低）
void conditional_loop(float* a, float* b, int n)
{
    for (int i = 0; i < n; i++) {
        if (a[i] > 0) {
            b[i] = a[i] * 2;
        } else {
            b[i] = a[i] / 2;
        }
    }
}

int main()
{
    const int N = 1000000;
    float* a = new float[N];
    float* b = new float[N];
    float* c = new float[N];
    float* result = new float[N];
    
    // 初始化
    for (int i = 0; i < N; i++) {
        a[i] = i * 1.0f;
        b[i] = i * 2.0f;
        c[i] = i * 3.0f;
    }
    
    // 性能测试
    auto start = std::chrono::high_resolution_clock::now();
    
    for (int iter = 0; iter < 100; iter++) {
        multiply_add(a, b, c, result, N);
    }
    
    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::milliseconds>(end - start);
    
    std::cout << "Time: " << duration.count() << " ms" << std::endl;
    std::cout << "Sample result: " << result[1000] << std::endl;
    
    delete[] a;
    delete[] b;
    delete[] c;
    delete[] result;
    
    return 0;
}
```

## GCC向量化命令

### 查看向量化报告

```bash
# 1. 只显示成功向量化的循环 ⭐ 推荐
g++ -O3 -march=native -o test test.cpp -fopt-info-vec-optimized

# 2. 只显示失败的循环（找出为什么没被向量化）
g++ -O3 -march=native -o test test.cpp -fopt-info-vec-missed

# 3. 显示所有信息（成功+失败+详细分析）📋 最详细
g++ -O3 -march=native -o test test.cpp -fopt-info-vec-all

# 4. 同时显示成功和失败（平衡）⭐ 常用
g++ -O3 -march=native -o test test.cpp \
    -fopt-info-vec-optimized \
    -fopt-info-vec-missed

# 5. 重定向到文件（信息太多时）
g++ -O3 -march=native -o test test.cpp \
    -fopt-info-vec-all 2>&1 | tee vectorization_report.txt
```

### 命令参数详解

```bash
g++ -O3 -march=native -o test test.cpp -fopt-info-vec-all
```

| 参数 | 作用 |
|------|------|
| `-O3` | **最高级别优化**，自动启用向量化 |
| `-march=native` | 为**当前CPU**生成指令（SSE/AVX/AVX2等） |
| `-o test` | 输出可执行文件名 |
| `-fopt-info-vec-all` | 打印**所有**向量化信息（成功+失败） |

### 优化级别对比

```bash
# O0 - 不优化，不向量化
g++ -O0 -o test_O0 test.cpp
time ./test_O0

# O1 - 基本优化，不向量化
g++ -O1 -o test_O1 test.cpp
time ./test_O1

# O2 - 中等优化，可能向量化
g++ -O2 -march=native -o test_O2 test.cpp -fopt-info-vec
time ./test_O2

# O3 - 激进优化，强力向量化 ⭐
g++ -O3 -march=native -o test_O3 test.cpp -fopt-info-vec
time ./test_O3

# Ofast - 最激进（可能牺牲精度）
g++ -Ofast -march=native -o test_Ofast test.cpp -fopt-info-vec
time ./test_Ofast
```

## 向量化报告解读

### ✅ 成功向量化

```bash
test.cpp:12:24: optimized: loop vectorized using 16 byte vectors
```

**含义：**
- **位置**：第12行第24列
- **结果**：循环被成功向量化
- **16 byte vectors**：使用128位SSE（4个float或2个double）
- **32 byte vectors**：使用256位AVX（8个float或4个double）

### ⚠️ 循环版本化

```bash
optimized: loop versioned for vectorization because of possible aliasing
```

**含义：**
- 编译器生成了**两个版本**的循环：
  1. **向量化版本**：指针不重叠时使用（快）
  2. **标量版本**：指针可能重叠时使用（安全）
- 运行时检查并选择合适的版本

**如何避免？** 使用 `__restrict__` 关键字：

```cpp
void func(float* __restrict__ a, float* __restrict__ b) {
    // 告诉编译器a和b不重叠，只生成向量化版本
}
```

### ❌ 无法向量化

```bash
test.cpp:28:24: missed: couldn't vectorize loop
test.cpp:29:22: missed: not vectorized: data dependency
```

**常见原因：**

| 原因信息 | 含义 | 示例 |
|----------|------|------|
| `data ref analysis failed` | 数据依赖分析失败 | `a[i] = a[i-1] + 1` |
| `loop contains function calls` | 循环包含函数调用 | `result[i] = sqrt(a[i])` |
| `control flow in loop` | 控制流太复杂 | 复杂的if-else |
| `not supported` | 不支持的操作 | 某些特殊操作 |

### 如果看到这些指令，说明向量化成功

#### SSE 指令（128位）

```asm
movups  xmm0, [rax]      # 加载4个float到xmm0
movups  xmm1, [rbx]      # 加载4个float到xmm1
addps   xmm0, xmm1       # 4个加法同时执行！
movups  [rcx], xmm0      # 存储结果
```

#### AVX 指令（256位）

```asm
vmovups ymm0, [rax]      # 加载8个float到ymm0
vmovups ymm1, [rbx]      # 加载8个float到ymm1
vaddps  ymm0, ymm0, ymm1 # 8个加法同时执行！
vmovups [rcx], ymm0      # 存储结果
```

## 容易向量化 vs 难以向量化

### ✅ 容易向量化的代码特征

#### 1. 简单的独立循环

```cpp
// ✅ 完美！每次迭代独立
for (int i = 0; i < n; i++) {
    c[i] = a[i] + b[i];
}
```

#### 2. 使用 `__restrict__` 关键字

```cpp
// ✅ 告诉编译器指针不重叠
void func(float* __restrict__ a, 
          float* __restrict__ b, 
          float* __restrict__ c) {
    for (int i = 0; i < n; i++) {
        c[i] = a[i] * b[i];
    }
}
```

#### 3. 数组对齐

```cpp
// ✅ SSE需要16字节对齐，AVX需要32字节对齐
alignas(16) float data[100];
alignas(32) float data_avx[100];

// 或动态分配
float* data = (float*)aligned_alloc(32, n * sizeof(float));
```

#### 4. 编译时已知的循环次数

```cpp
// ✅ 常量循环次数
#define N 1024
for (int i = 0; i < N; i++) {
    c[i] = a[i] + b[i];
}
```

### ❌ 难以向量化的代码特征

#### 1. 有数据依赖

```cpp
// ❌ 当前迭代依赖前一次的结果
for (int i = 1; i < n; i++) {
    data[i] = data[i-1] + data[i];  // 无法并行
}

// ❌ 累加
float sum = 0;
for (int i = 0; i < n; i++) {
    sum += data[i];  // 有依赖
}
```

#### 2. 复杂的控制流

```cpp
// ⚠️ 可能被向量化，但效率降低
for (int i = 0; i < n; i++) {
    if (a[i] > 0) {
        result[i] = sqrt(a[i]);
    } else if (a[i] < 0) {
        result[i] = -sqrt(-a[i]);
    } else {
        result[i] = 0;
    }
}
```

#### 3. 函数调用

```cpp
// ❌ 难以向量化（除非函数被内联）
for (int i = 0; i < n; i++) {
    result[i] = expensive_function(data[i]);
}
```

#### 4. 指针别名问题

```cpp
// ❌ 编译器不确定a和b是否重叠
void func(float* a, float* b) {
    for (int i = 0; i < 100; i++) {
        b[i] = a[i] * 2;  // b可能指向a的一部分
    }
}
```

## 性能对比

### 完整基准测试代码

```cpp
#include <iostream>
#include <chrono>
#include <xmmintrin.h>  // SSE

const int N = 10000000;

// 版本1：编译器自动向量化
void auto_vectorized(float* __restrict__ a, 
                     float* __restrict__ b, 
                     float* __restrict__ c, 
                     float* __restrict__ result, 
                     int length)
{
    for (int i = 0; i < length; i++) {
        result[i] = a[i] * b[i] + c[i];
    }
}

// 版本2：手动使用Intrinsics
void manual_sse(float* a, float* b, float* c, float* result, int length)
{
    for (int i = 0; i < length; i += 4) {
        __m128 va = _mm_loadu_ps(&a[i]);
        __m128 vb = _mm_loadu_ps(&b[i]);
        __m128 vc = _mm_loadu_ps(&c[i]);
        __m128 vr = _mm_add_ps(_mm_mul_ps(va, vb), vc);
        _mm_storeu_ps(&result[i], vr);
    }
}

// 版本3：标量版本（禁用向量化）
#pragma GCC push_options
#pragma GCC optimize ("no-tree-vectorize")
void scalar_version(float* a, float* b, float* c, float* result, int length)
{
    for (int i = 0; i < length; i++) {
        result[i] = a[i] * b[i] + c[i];
    }
}
#pragma GCC pop_options

double benchmark(void (*func)(float*, float*, float*, float*, int),
                 float* a, float* b, float* c, float* result, int length,
                 const char* name)
{
    auto start = std::chrono::high_resolution_clock::now();
    
    for (int iter = 0; iter < 100; iter++) {
        func(a, b, c, result, length);
    }
    
    auto end = std::chrono::high_resolution_clock::now();
    auto duration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
    
    double time_ms = duration.count() / 1000.0;
    std::cout << name << ": " << time_ms << " ms" << std::endl;
    
    return time_ms;
}

int main()
{
    // 对齐分配内存（对SIMD友好）
    float* a = (float*)aligned_alloc(32, N * sizeof(float));
    float* b = (float*)aligned_alloc(32, N * sizeof(float));
    float* c = (float*)aligned_alloc(32, N * sizeof(float));
    float* result = (float*)aligned_alloc(32, N * sizeof(float));
    
    // 初始化
    for (int i = 0; i < N; i++) {
        a[i] = 1.0f + i * 0.001f;
        b[i] = 2.0f + i * 0.001f;
        c[i] = 3.0f;
    }
    
    std::cout << "数组大小: " << N << " 个float" << std::endl;
    std::cout << "循环迭代: 100 次\n" << std::endl;
    
    double t_scalar = benchmark(scalar_version, a, b, c, result, N, "标量版本      ");
    double t_auto = benchmark(auto_vectorized, a, b, c, result, N, "自动向量化    ");
    double t_manual = benchmark(manual_sse, a, b, c, result, N, "手动SSE       ");
    
    std::cout << "\n相对于标量版本的加速比:" << std::endl;
    std::cout << "  自动向量化: " << (t_scalar / t_auto) << "x" << std::endl;
    std::cout << "  手动SSE:    " << (t_scalar / t_manual) << "x" << std::endl;
    std::cout << "\n验证结果: " << result[1000] << std::endl;
    
    free(a);
    free(b);
    free(c);
    free(result);
    
    return 0;
}
```

# 运行

## 向量化辅助指令

### 强制向量化

```cpp
#pragma GCC ivdep  // GCC
#pragma clang loop vectorize(enable)  // Clang
#pragma loop(ivdep)  // MSVC

for (int i = 0; i < n; i++) {
    c[i] = a[i] + b[i];
}
```

### 禁用向量化

```cpp
#pragma GCC novector  // GCC 11+
#pragma clang loop vectorize(disable)  // Clang

for (int i = 0; i < n; i++) {
    c[i] = a[i] + b[i];
}
```

## 最佳实践

### ✅ 推荐做法

1. **使用 `-O3 -march=native`**
```bash
g++ -O3 -march=native -o program program.cpp
```

2. **使用 `__restrict__` 避免指针别名**
```cpp
void func(float* __restrict__ a, float* __restrict__ b);
```

3. **使用对齐的内存**
```cpp
alignas(32) float data[N];
```

4. **简化循环逻辑**
```cpp
// 好：简单清晰
for (int i = 0; i < n; i++) {
    c[i] = a[i] + b[i];
}
```

5. **查看向量化报告，优化未向量化的循环**
```bash
g++ -O3 -march=native -fopt-info-vec-all ...
```

## 完整的最佳编译命令

```bash
# 推荐的生产环境编译命令
g++ -O3 \
    -march=native \              # 使用本机CPU的最佳指令
    -mtune=native \              # 针对本机CPU调优
    -ffast-math \                # 允许更激进的浮点优化
    -funroll-loops \             # 循环展开
    -flto \                      # 链接时优化
    -o program program.cpp \
    -fopt-info-vec-optimized \   # 只看成功向量化的
    -fopt-info-vec-missed        # 也看失败的原因
```

## 总结

### 关键要点

✅ **现代编译器（GCC、Clang）的自动向量化非常强大**  
✅ **不是Intel编译器专属，GCC也能做得很好**  
✅ **简单的循环通常能达到接近手写SIMD的性能**  
✅ **`-O3 -march=native -fopt-info-vec-all` 可以查看详细的向量化报告**  
✅ **"Packaged single float data" = 把多个float打包成SIMD向量处理**  

### 三种方式选择

| 方式 | 适用场景 | 推荐度 |
|------|---------|--------|
| **自动向量化** | 简单循环，快速开发 | ⭐⭐⭐⭐⭐ |
| **Intrinsics** | 需要精确控制，复杂算法 | ⭐⭐⭐⭐ |
| **内联汇编** | 极致性能，特殊指令 | ⭐⭐ |

### 编译器能力对比

| 编译器 | 向量化能力 | 推荐度 |
|--------|-----------|--------|
| **GCC** | ⭐⭐⭐⭐⭐ | 首选（开源、跨平台） |
| **Clang** | ⭐⭐⭐⭐⭐ | 首选（开源、跨平台） |
| **Intel ICC** | ⭐⭐⭐⭐⭐ | 最强（但不免费） |
| **MSVC** | ⭐⭐⭐⭐ | Windows首选 |
