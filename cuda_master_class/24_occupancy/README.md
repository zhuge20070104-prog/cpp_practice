# GPU 占用率与延迟隐藏

## 核心概念

GPU通过**多个warp并发执行**来隐藏指令延迟，最大化SM内部各执行单元的利用率。

## SM内部的执行单元

```
┌─────────────────────────────────────────────┐
│                    SM                       │
├─────────────────────────────────────────────┤
│  🔢 ALU/FPU单元 (算术逻辑运算)             │
│     - 加减乘除、逻辑运算                    │
│     - 128个CUDA Core                       │
│                                             │
│  💾 LD/ST单元 (内存访问)                   │
│     - 发射内存读写请求                      │
│     - 延迟最长（~400周期）                  │
│                                             │
│  🧮 SFU单元 (特殊函数)                     │
│     - sin/cos/sqrt/exp等                   │
│     - 延迟中等（~20周期）                   │
└─────────────────────────────────────────────┘
```

## 单个Warp的执行瓶颈

### 示例代码：

```cuda
__global__ void kernel(float *a, float *b, float *c) {
    int tid = threadIdx.x;
    
    float x = a[tid];           // LD: 内存读取
    float y = b[tid];           // LD: 内存读取
    float z = x * y + 1.0f;     // ALU: 乘加运算
    float w = sqrtf(z);         // SFU: 开方
    c[tid] = w;                 // ST: 内存写入
}
```

### 单个Warp的执行时间线：

```
周期      W1执行指令         ALU状态   LD/ST状态   SFU状态
─────────────────────────────────────────────────────────
1-2      float x = a[tid]   空闲🔴    工作🟢      空闲🔴
3-400    等待内存数据       空闲🔴    空闲🔴      空闲🔴  ← 浪费！
401-402  float y = b[tid]   空闲🔴    工作🟢      空闲🔴
403-800  等待内存数据       空闲🔴    空闲🔴      空闲🔴  ← 浪费！
801-810  float z = x*y+1    工作🟢    空闲🔴      空闲🔴
811-830  float w = sqrtf    空闲🔴    空闲🔴      工作🟢
831-832  c[tid] = w         空闲🔴    工作🟢      空闲🔴
833-1230 等待写入完成       空闲🔴    空闲🔴      空闲🔴  ← 浪费！

问题：大量时间在等待，执行单元空闲率 > 99%！
```

## 占用率计算

**需要的Warp数量取决于最长延迟：**

```
单元类型       延迟        覆盖所需warp数（假设4路并行）
──────────────────────────────────────────────
ALU           ~10周期     4 × 10 = 40个warp
SFU           ~20周期     4 × 20 = 80个warp
LD/ST         ~400周期    4 × 400 = 1600个warp！

瓶颈：内存访问延迟最长，需要最多warp来隐藏
```

## 总结

**多warp的核心目标 = 提高所有执行单元（ALU、LD/ST、SFU）的利用率**

- ✅ 当某些warp等待内存时 → 其他warp用ALU计算
- ✅ 当某些warp在计算时 → 其他warp访问内存  
- ✅ 当某些warp用SFU时 → 其他warp用ALU/LD/ST
- ✅ **所有功能单元保持100%利用率 = 最大吞吐量**

这就是GPU通过**大规模并行**实现高性能的根本机制！🚀
